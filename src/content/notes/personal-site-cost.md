前几天我看了一下这个网站现在到底花多少钱。

算完以后是 **一年大约 272 元**。比我印象里便宜不少。

先把账放这里。

| 项目 | 当前费用 |
| --- | ---: |
| `yanxiao.me` 域名 | 135 元 / 年 |
| Function Compute | 126 元 / 年 |
| HTTPS 证书 | 0 元 |
| OSS + CDN | 每天不超过 0.03 元 |

OSS 和 CDN 都是按量付费。按每天 0.03 元直接往高了算，一年也就是 10.95 元。

```text
135 + 126 + 10.95 = 271.95 元
```

所以目前最大的两块开销，实际上是域名和函数计算资源包。静态文件的存储和流量反而没多少钱。

## 126 元的 Function Compute 够不够

我现在用的是一年 120 万 CU 的资源包，126 元。

这个网站绝大部分是静态页面，真正会调用后端的功能并不多，所以目前完全够用。

另外我把函数的最小实例数设成了 0。

这会带来冷启动。第一次进动态页面时，偶尔要等几秒。我实测下来通常不会太久，前端现在也会把等待过程直接显示出来。

我考虑过保留一个常驻实例。好处当然是快，代价就是一天 24 小时都要为那一点计算资源付费。

以现在的访问量，我觉得没必要。

有人用的时候等几秒，没人用的时候别跑，这个取舍目前比较适合我。

## 证书现在是免费的

HTTPS 用的是免费证书，所以这项现在是 0 元。

如果以后换成收费 DV 证书，账单会明显多一块。比如按一年 190 元算，总费用就会到 460 元左右。

不过我暂时没有为了“以后可能需要”提前花这笔钱的打算。到期的时候再看当时有哪些方案。

云产品价格也一样。资源包便宜就用资源包，访问量真上去了再重新算。

## 我不太想为个人网站养一台机器

如果买一台固定云服务器，账其实也未必贵到哪里去。真正让我不想用它的，是后面的维护。

系统更新、磁盘、日志、服务状态、证书、端口、安全配置……这些事情每一项都不难，但会一直在那里。

现在静态内容放 OSS，流量走 CDN，偶尔需要后端时再启动 Function Compute。我基本不用考虑某台机器今天是不是还活着。

这对我比单纯省几十块钱更有吸引力。

当然，现在便宜和访问量低有很大关系。这个站一天也没有多少请求，不能拿这个数字去代表别的网站。

我只是想留一份自己的账。以后哪天一年花到几千块，再回来看看钱到底是从哪里开始涨的。
